# TraceLite Documentation

**TraceLite** is a lightweight request & response tracing tool for Python web applications.
It supports popular frameworks such as **Flask, Django, and FastAPI** and provides a simple, structured logging mechanism with an embedded web dashboard and CLI viewer.

## Key Features
- Middleware-based HTTP request and response logging
- Embedded web dashboard at `/_tracelite`
- Configurable filters and data masking
- SQLite storage
- CLI viewer with Rich tables
- Easy-to-configure `tracelite.toml`
